# Docs map

| Path | Holds |
|------|-------|
| `docs/brief.md` | Mission, non-goals, priorities: the yardstick for every decision |
| `docs/status.md` | Present state |
| `docs/todo.md` | Next work, in order |
| `docs/decisions/` | One file per topic, append-only, dated entries |
| `docs/features/` | One page per feature as it exists now, with a `Verified · Sources` header |
| `docs/guides/` | How to run, test and release, with a `Verified · Sources` header |
| `docs/code/` | One mirror per source file: why, invariants, ordering; never a restatement of the code |

Every page in `docs/features/` and `docs/guides/` is listed below.
