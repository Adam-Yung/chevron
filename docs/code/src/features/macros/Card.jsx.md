# src/features/macros/Card.jsx

A site in the menu, as a real button. The name is always shown; the Shift+letter hint shows the macro's actual `key`. The old hint
showed the first letter of the name, which was wrong for most sites (Telegram's key is M). The filter match is highlighted in the name.

The card is a sewn badge: felt from the macro's first colour, icon and stitch ring in `thread`. The key letter sits inside the badge element so it stays beside it when a grid cell is much taller than the badge (phones).
